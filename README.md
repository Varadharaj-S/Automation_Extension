# Automation_Extension
# 🧩 DSA Tracker Chrome Extension

This Chrome Extension securely connects your **LeetCode** account to the **DSA Tracker** backend, allowing automatic synchronization of your solved problems.

---

# ✨ Features

- 🔐 Secure LeetCode session integration
- ⚡ One-click connection to DSA Tracker
- 📊 Automatic problem synchronization
- 🚀 Works with the DSA Tracker backend
- 🔄 No manual cookie copying required

---

# 📥 Installation

## Step 1: Download the Extension

Clone this repository or download it as a ZIP file.

```bash
git clone https://github.com/Varadharaj-S/Automation_Extension.git
```

Or click **Code → Download ZIP** and extract it.

---

## Step 2: Open Chrome Extensions

Open Chrome and go to:

```
chrome://extensions
```

---

## Step 3: Enable Developer Mode

Turn on **Developer mode** using the toggle in the top-right corner.

---

## Step 4: Load the Extension

Click **Load unpacked**.

Select the downloaded **Automation_Extension** folder.

Example:

```
Automation_Extension/
│
├── manifest.json
├── popup.html
├── popup.js
├── background.js
└── content.js
```

The extension will now appear in Chrome.

---

# 🔗 Connect to DSA Tracker

## Step 1

Open your deployed DSA Tracker website.

Example:

```
https://your-app.onrender.com
```

Login to your account.

---

## Step 2

Open **https://leetcode.com** and sign in.

---

## Step 3

Click the **DSA Tracker Extension**.

---

## Step 4

Enter your backend URL.

https://automation-bot-0i02.onrender.com
```

---

## Step 5

Click **Connect LeetCode**.

If successful, you'll see:

```
✅ LeetCode Connected Successfully
```

Your LeetCode session will be securely stored in the DSA Tracker backend.

# ⚠️ Notes

- You must be logged in to LeetCode.
- Enable Developer Mode before loading the extension.
- Keep your backend URL running.
- The extension works only with your own DSA Tracker backend.

---

# 🔒 Security

- Your session is sent only to your configured DSA Tracker backend.
- No third-party servers are used.
- The extension does not store your LeetCode password.
